# What's new in 1.1.0

- **Gallery edit mode**: switch the image viewer to Edit (or press M) to tag images and add them to playlists one after another.
- **Import preview opens in the page**: double-clicking a staged file now opens it over the Import page like the Gallery's viewer, instead of in a popup, with full screen (F11) and hide controls (Z).
- **Tag menu while tagging**: right-click a tag in the import preview or edit mode to rename, recolor, merge or delete it, the same as on the Tags page.
